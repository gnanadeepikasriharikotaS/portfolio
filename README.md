# 🌐 Responsive Portfolio Website

A clean, modern, and fully responsive personal portfolio built using **pure HTML, CSS, and JavaScript**.

This portfolio showcases my skills, projects, and achievements in a visually appealing and mobile-friendly design.  
With **no external frameworks**, the website is lightweight, fast, and optimized for all screen sizes.

---

## 🚀 Features

- ✅ **Fully Responsive Design** – Works on desktop, tablet, and mobile  
- ✅ **Pure HTML, CSS & JavaScript** – No frameworks used  
- ✅ **Modern UI/UX** with smooth transitions  
- ✅ **Dedicated Sections** – About, Skills, Projects, Contact  
- ✅ **Reusable & Clean Code Structure**  
- ✅ **Optimized for Fast Load Time**  
- ✅ **Interactive Navigation Menu**

---

## 🎨 Technologies Used

- **HTML5** – Page structure  
- **CSS3** – Styling, animations, responsiveness  
- **JavaScript (ES6)** – Interactivity & dynamic UI
